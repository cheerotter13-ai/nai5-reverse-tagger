# Public NAI5 reverse tagger

Open-source web tool: image → NovelAI V5 boxes.

- Character boxes: Danbooru short tags + `source#` / `target#`.
- Base box: count / theme / scene / camera / `nsfw`.
- One NL sentence for spatial layout and complex interaction.
- No wildcard folding of character, outfit, expression, or action.

Private folding / production slots stay on `feat/nai5-tagger`.
