> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local NAI5 reverse tagger that turns one anime NSFW image into a paste-ready base prompt plus per-character boxes with `source#` / `target#` / `mutual#`.

**Architecture:** Pure `compile(SceneDraft, list[TagHit], CompileOptions) -> Nai5Prompt` sits in the middle. `pipeline` optionally short-circuits on NovelAI metadata, otherwise runs WD14 and Grok vision in parallel and feeds both into the compiler. CLI and a localhost page only render `Nai5Prompt`.

**Tech Stack:** Python 3.11+, pytest, Pillow, numpy, onnxruntime, stdlib `http.server` / `urllib`. No Pydantic. No dependency on the NovelAI toolkit or the WD14 story-tagging repo.

**Spec:** `docs/superpowers/specs/2026-09-09-nai5-tagger-design.md`

```python
from __future__ import annotations
from dataclasses import dataclass, field
from typing import Literal

Gender = Literal["girl", "boy", "other"]
ActionRole = Literal["source", "target", "mutual"]

@dataclass
class Action:
    role: ActionRole
    verb: str

@dataclass
class CharacterDraft:
    gender: Gender
    identity: str = ""
    appearance: list[str] = field(default_factory=list)
    clothing: list[str] = field(default_factory=list)
    pose: list[str] = field(default_factory=list)
    expression: list[str] = field(default_factory=list)
    actions: list[Action] = field(default_factory=list)

@dataclass
class SceneDraft:
    count_tag: str
    themes: list[str]
    scene: list[str]
    camera: list[str]
    nsfw: bool
    nl: str
    characters: list[CharacterDraft]

    @classmethod
    def from_dict(cls, data: dict) -> "SceneDraft":
        chars = []
        for raw in data.get("characters") or []:
            actions = [
                Action(role=a["role"], verb=a["verb"])
                for a in raw.get("actions") or []
            ]
            chars.append(
                CharacterDraft(
                    gender=raw["gender"],
                    identity=raw.get("identity") or "",
                    appearance=list(raw.get("appearance") or []),
                    clothing=list(raw.get("clothing") or []),
                    pose=list(raw.get("pose") or []),
                    expression=list(raw.get("expression") or []),
                    actions=actions,
                )
            )
        return cls(
            count_tag=data["count_tag"],
            themes=list(data.get("themes") or []),
            scene=list(data.get("scene") or []),
            camera=list(data.get("camera") or []),
            nsfw=bool(data.get("nsfw")),
            nl=data.get("nl") or "",
            characters=chars,
        )

@dataclass
class TagHit:
    name: str
    score: float
    category: int

@dataclass
class CompileOptions:
    include_nl: bool | None = None
    uc_preset: str = "default"

@dataclass
class BasePrompt:
    tags: list[str]
    nl: str

@dataclass
class CharacterPrompt:
    gender: Gender
    identity: str
    appearance: list[str]
    clothing: list[str]
    pose: list[str]
    expression: list[str]
    actions: list[Action]

@dataclass
class UcBlock:
    preset: str
    extra: list[str]

@dataclass
class PromptMeta:
    source: Literal["metadata", "reverse"]
    count_tag: str
    wd14_skipped: bool
    character_count: int

@dataclass
class Nai5Prompt:
    base: BasePrompt
    characters: list[CharacterPrompt]
    uc: UcBlock
    unassigned: list[str]
    ignored: list[str]
    warnings: list[str]
    meta: PromptMeta

@dataclass
class MetadataResult:
    base_caption: str
    char_captions: list[str]
    uc: str = ""
```

def _all_text(prompt) -> str:
    parts = list(prompt.base.tags)
    for ch in prompt.characters:
        parts.extend([ch.gender, ch.identity, *ch.appearance, *ch.clothing, *ch.pose, *ch.expression])
        parts.extend([f"{a.role}#{a.verb}" for a in ch.actions])
    return ", ".join(p for p in parts if p).lower()

- [ ] **Step 3: Write minimal implementation**

`make_server(host, port)` returns `ThreadingHTTPServer`. Handler:

- `GET /` serves `data/index.html`.
- `GET /api/ready` → `{"ok": gateway_ready(), "error": "..."}`. If not ok, still HTTP 200 with `ok:false` so the page can show 「Grok 网关不可用」 and disable reverse.
- `POST /api/reverse` saves upload to temp, `run_pipeline`, returns `{prompt: asdict, text: render(prompt), error: null}` or `{error, exit_code}`.
- `POST /api/assign` rebuilds `Nai5Prompt` from dict (add `Nai5Prompt.from_dict` in `types.py`), `assign_unassigned`, returns new prompt+text. Does not call Grok/WD14.
- Bind `127.0.0.1` only.

`index.html` (Chinese UI, no art-style controls):

- Drop zone + file input.
- Status line: metadata / wd14 / grok / compile / error text (server can return a single `error`; client shows it).
- Boxes: Prompt, Character 1..N, UC, each with 复制. Button 复制全部.
- Warnings list. Unassigned chips that POST `/api/assign` dest `char:i` or `base`.
- Ignored list collapsed `<details>`.
- Checkbox 自然语言, default checked; send `include_nl` form field to `/api/reverse`.
- On load, GET `/api/ready`; if not ok, disable the run button and show the error.
